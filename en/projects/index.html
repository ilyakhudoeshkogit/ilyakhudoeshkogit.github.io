Executive Dashboard

personal / learning project
DrawnKhudoeshko I.
StackSPFx 1.23 · React · Fluent UI v9 · PnPjs

A manager's dashboard for SharePoint: overview, approvals, projects and key documents in one web part. Data comes from SharePoint lists.

Result: a manager sees approvals, project status and documents on one page and decides on a request with one click.

Technical requirements

  1. Tabs: overview, approvals, projects, documents
  2. Approve / Reject with Undo
  3. Projects by department: Green / Yellow / Red status, progress, add a project
  4. Reads and writes lists through PnPjs

Desk Reservation

personal / learning project
DrawnKhudoeshko I.
StackSPFx 1.23 · React · Fluent UI · REST

Desk booking: pick a date and a zone, see free desks as cards and book one. All data lives in SharePoint lists, there is no separate backend.

Result: an employee finds a free desk for the date they need and books it in SharePoint, with no separate spreadsheets.

Technical requirements

  1. Filter by date and zone, booked desks are hidden
  2. "My reservations" and cancelling a booking
  3. Success, warning and error messages
  4. HLD, user guide and deployment guide written for it

Teams Photo Bot

learning project
DrawnKhudoeshko I.
StackC# · ASP.NET Core · Bot Framework v4 · Graph

A Microsoft 365 ecosystem project: a Teams bot. On the command "photo" it fetches the user's profile photo from Microsoft Graph and replies with a card.

Result: a user types "photo" to the bot in Teams and gets a card with their profile photo.

Technical requirements

  1. Adaptive Card with the name and photo
  2. Graph access through an Entra ID app (Azure.Identity)
  3. Fallback when there is no photo
  4. No secrets in the repo: only placeholders in the settings
