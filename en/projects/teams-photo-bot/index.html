StackC# · ASP.NET Core · Bot Framework v4 · Graph

A Microsoft 365 ecosystem project: a Teams bot. On the command "photo" it fetches the user's profile photo from Microsoft Graph and replies with a card.

Result: a user types "photo" to the bot in Teams and gets a card with their profile photo.

Technical requirements

  1. Adaptive Card with the name and photo
  2. Graph access through an Entra ID app (Azure.Identity)
  3. Fallback when there is no photo
  4. No secrets in the repo: only placeholders in the settings

02 · Live demo

Microsoft Teams · Photo Bot

Quick commands: 

Ask for a card with the photo command first.

The demo runs only in your browser: the profile is fictional and messages are not sent anywhere. The real bot answers in Teams and takes the data from Microsoft Graph.

The demo needs JavaScript.

03 · Message flow

Teams passes the message through Bot Service to the bot endpoint. The bot gets an Entra ID app token through Azure.Identity, requests the user photo from Microsoft Graph and replies with an Adaptive Card. If there is no photo (404), the card keeps the initials. Keys are stored outside the repository.
