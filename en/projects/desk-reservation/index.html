Desk Reservation

personal / learning project
DrawnKhudoeshko I.
StackSPFx 1.23 · React · Fluent UI · REST

Desk booking: pick a date and a zone, see free desks as cards and book one. All data lives in SharePoint lists, there is no separate backend.

Result: an employee finds a free desk for the date they need and books it in SharePoint, with no separate spreadsheets.

Technical requirements

  1. Filter by date and zone, booked desks are hidden
  2. "My reservations" and cancelling a booking
  3. Success, warning and error messages
  4. HLD, user guide and deployment guide written for it
FrameworkSPFx 1.23
UIReact · Fluent UI v9
DataDesks and Reservations lists, REST (SPHttpClient)
ZonesOpen Space, Quiet Zone, Meeting Room
Backendnone, SharePoint only
Statuspersonal / learning project
Codeprivate, on request

02 · Live demo

  • free, click a desk
  • booked or under repair
  • your booking

The demo runs only in your browser: desks and bookings are fictional and stored in localStorage. In the real web part the same actions go to SharePoint lists.

The demo needs JavaScript.

03 · Data schema

Two SharePoint lists. The web part reads desks and reservations over REST (SPHttpClient), hides desks already booked for the chosen date, writes a new booking with a POST request and deletes it on cancel.
