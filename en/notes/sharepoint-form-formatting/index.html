SharePoint list form formatting: a JSON builder

Build the header, body and footer for "Format form": icon and title, field sections and footer actions, with a live preview and a Copy button.

After column formatting, the natural next step is the item form itself. In modern SharePoint lists it has three zones: header, body with sections and footer. Writing JSON for each by hand is slow: header/footer share one schema (column formatting), body uses another (sections). So I built a builder next to column formatting.

How body differs from header

Header and footer are an elmType tree, like column formatting: a Fluent icon, text with [$Title] tokens, links. Body only does layout: a sections array with field display names. Conditional field visibility is a separate formula under Edit columns, not part of the body JSON. Presets come from my projects: approvals in Executive Dashboard and bookings in Desk Reservation.

The schema is checked against Configure the list form on Microsoft Learn, 6 Nov 2026. The builder runs only in the browser and sends nothing anywhere.
