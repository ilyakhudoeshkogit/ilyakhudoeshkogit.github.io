Which Node and React does my SPFx version need

An interactive cheat sheet: SPFx version → Node.js, TypeScript, React, gulp or Heft, SharePoint Server support. Checks node -v and package.json right in the browser.

The most common reason an SPFx project does not build after git clone is the wrong Node or React version. I keep this table at hand, so I turned it into a tool: pick a version or paste a package.json and it shows what to install.

Things to remember

Install React at exactly the version from the table with --save-exact: with a newer one the build passes but the web part silently breaks in the browser. Since 1.22 Heft replaces gulp, so the old gulp serve and gulp bundle commands do not work in new projects.

On-premises SharePoint Server only supports old versions: Subscription Edition up to 1.5, 2019 up to 1.4.1, 2016 with Feature Pack 2 up to 1.1. Anything newer runs only in SharePoint Online.

Data source: the Microsoft Learn compatibility table, checked on 30 Oct 2026. The tool runs only in the browser and sends nothing anywhere.
