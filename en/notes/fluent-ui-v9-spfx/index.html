Fluent UI v9 in an SPFx web part

How Fluent UI v9 is wired into Executive Dashboard: FluentProvider with a theme, TabList tabs, cards and a loading spinner.

SPFx 1.23 ships with Fluent UI v8 (@fluentui/react). For Executive Dashboard I took v9, the @fluentui/react-components package: its styles come from theme tokens. Both versions live fine in one package.json.

The theme provider

v9 components take colours and fonts from FluentProvider. I put it once, at the root of the web part. Without it buttons and cards stay unstyled.

import {
  FluentProvider, webLightTheme, TabList, Tab,
  Card, Text, Spinner, SelectTabEventHandler
} from '@fluentui/react-components';

return (
  <FluentProvider theme={webLightTheme}>
    ...
  </FluentProvider>
);

Tabs

Section navigation is a TabList. Each tab label shows the item count, and the selected tab is kept in React state.

const handleTabSelect: SelectTabEventHandler = (event, data): void => {
  setSelectedTab(String(data.value));
};

<TabList selectedValue={selectedTab} onTabSelect={handleTabSelect}>
  <Tab value="overview">Overview</Tab>
  <Tab value="approvals">My Approvals ({approvals.length})</Tab>
  <Tab value="projects">Projects ({projects.length})</Tab>
  <Tab value="documents">Documents ({documents.length})</Tab>
</TabList>

Loading

While the service reads the lists, a <Spinner label="Loading dashboard data..." /> is shown instead of the tabs, then Card components with Text. See the Executive Dashboard screenshots.
