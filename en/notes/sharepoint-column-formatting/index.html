SharePoint column formatting without code: a JSON builder

Pick what to highlight, a status, a number or a due date, and get ready JSON for "Format this column" with a live preview and hints about the usual mistakes.

Not every task needs a web part. If a client wants overdue tasks to turn red and approved requests to turn green, column formatting is enough: it is JSON pasted straight into the list settings, with no build and no deployment. Writing it by hand is awkward because of the nested if calls, so I built a builder.

Example:

Value → level

When formatting is not enough

Formatting only draws the value: it does not total anything, does not read other lists and cannot save anything beyond simple actions like setValue. As soon as you need data from two lists or your own logic, that is a web part, like Executive Dashboard. The sp-field-severity--* classes and Fluent icons come from the Microsoft documentation, so they look the same in SharePoint's dark and light themes.

The syntax is checked against the column formatting docs on Microsoft Learn. The builder runs only in the browser and sends nothing anywhere.
