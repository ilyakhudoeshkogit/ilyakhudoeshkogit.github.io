SPFx web part property pane builder

Add property pane fields and get the props interface, getPropertyPaneConfiguration() with imports, the manifest properties block and the loc strings at once, with a live pane preview.

A single SPFx web part property lives in five places: the props interface, getPropertyPaneConfiguration(), the manifest as a default value and two loc files as a label. Forget one and the build fails or the pane shows an empty label. So I built a builder: describe the fields once and it writes all five pieces, with a preview of how the pane will look.

Example:

Pane fields

Reactive and non-reactive pane

By default the pane is reactive: every change goes straight into this.properties and the web part re-renders. If re-rendering is expensive, for example each time it queries a list, turn on disableReactivePropertyChanges: an Apply button appears, and while onGetErrorMessage returns an error it is disabled. The preview shows this in the this.properties block: in non-reactive mode it only changes after Apply.

The presets come from my projects: Executive Dashboard (the approvals list and KPI tiles) and Desk Reservation (the desks list, zone and booking horizon). Dropdown options here are set in code; if they come from SharePoint they are loaded asynchronously, as in the bookings on two lists write-up.

API and import names are checked against the Microsoft Learn docs on 3 Nov 2026: configuring the property pane, validating values, cascading dropdowns, preconfiguredEntries, loadPropertyPaneResources and the @microsoft/sp-property-pane reference. The builder runs only in the browser and sends nothing anywhere.
