A SharePoint site template without the PowerShell grind: a site script builder

Describe lists, columns, navigation, theme and hub and get a ready site-script.json with stable GUIDs, registration scripts for SPO and PnP PowerShell and a sketch of the future site.

When a portal has several departments, nobody creates the same lists and menus on every site by hand. For Halden I wrote a PowerShell deployment, but SharePoint Online has a simpler way: a site template built from a JSON script of actions. You register it once, and any site owner applies it from "Apply a site template". The JSON is long, and Choice and lookup columns are written as escaped CAML, so I built a builder.

Example:

Site

Site script or a PnP template

A site script can only do what is in its list of actions: lists, columns, views, navigation, theme, hub, installing a solution and starting a Power Automate flow. It does not create pages with web parts, per-list permissions or data. For that you call a flow with triggerFlow or use a PnP template, as in Halden. A handy middle ground: the site template builds the skeleton, and web parts like Desk Reservation are added with installSolution from the App Catalog.

Actions, parameters and limits are checked against Microsoft Learn on 10 Nov 2026: the site template overview (types 64, 1, 68; 30 actions for Invoke-SPOSiteDesign, 300 actions or 100,000 characters when applied asynchronously) and the JSON schema. The builder runs only in the browser and sends nothing anywhere.
