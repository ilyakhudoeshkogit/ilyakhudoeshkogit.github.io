Provisioning SharePoint lists with PnP.PowerShell

How the Halden portal deployment script creates lists and fields from JSON and survives a re-run.

The Halden portal is deployed by one script, Provision-Halden.ps1. The lists are described separately in portal-lists.json, and the script only reads it and brings the site to that state. The key requirement: it can be re-run any number of times.

List definition

{
  "key": "people",
  "title": "Halden People",
  "url": "Lists/HaldenPeople",
  "library": false,
  "fields": [
    { "name": "HaldenJobTitle", "display": "Job title", "type": "Text" },
    { "name": "HaldenDepartment", "display": "Department", "type": "Choice",
      "choices": ["Executive", "HR", "Finance", "IT", "Sales", "PMO", "Marketing"] }
  ]
}

Create only if missing

A list is created only if Get-PnPList did not find it. Then missing fields are added one by one: if the field already exists on the site it is attached to the list, otherwise it is created from XML.

$list = Get-PnPList -Identity $def.title -ErrorAction SilentlyContinue
if (-not $list) {
  $template = if ($def.library) { 'DocumentLibrary' } else { 'GenericList' }
  $list = New-PnPList -Title $def.title -Url $leafUrl -Template $template
}
Ensure-ListFields -ListTitle $def.title -Fields $def.fields
function Ensure-ListFields {
  param([string] $ListTitle, $Fields)
  $current = @(Get-PnPField -List $ListTitle | ForEach-Object { $_.InternalName })
  foreach ($def in $Fields) {
    if ($current -contains [string] $def.name) { continue }
    $siteField = Get-PnPField -Identity ([string] $def.name) -ErrorAction SilentlyContinue
    if ($siteField) { Add-PnPField -List $ListTitle -Field ([string] $def.name) | Out-Null }
    else { Add-PnPFieldFromXml -List $ListTitle -FieldXml (Get-FieldXml -Def $def) | Out-Null }
  }
}

A field from its definition

The Get-FieldXml function turns a JSON entry into Field XML by type: Choice, DateTime, Note, Boolean, Number or Text. Display names are escaped so quotes and ampersands do not break the XML.

'Choice' {
  $choices = ($Def.choices | ForEach-Object {
    '<CHOICE>' + [System.Security.SecurityElement]::Escape([string] $_) + '</CHOICE>' }) -join ''
  return "<Field Type='Choice' Name='$name' StaticName='$name' DisplayName='$display' Format='Dropdown'><CHOICES>$choices</CHOICES></Field>"
}
