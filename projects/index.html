Executive Dashboard

личный / учебный проект
Разраб.Худоешко И.О.
СтекSPFx 1.23 · React · Fluent UI v9 · PnPjs

Панель руководителя для SharePoint: обзор, согласования, проекты и ключевые документы в одной веб-части. Данные берёт из списков SharePoint.

Результат: руководитель видит согласования, статусы проектов и документы на одной странице и решает по заявке одним нажатием.

Технические требования

  1. Вкладки: обзор, согласования, проекты, документы
  2. Approve / Reject с отменой действия (Undo)
  3. Проекты по отделам: статус Green / Yellow / Red, прогресс, добавление проекта
  4. Чтение и запись списков через PnPjs

Desk Reservation

личный / учебный проект
Разраб.Худоешко И.О.
СтекSPFx 1.23 · React · Fluent UI · REST

Бронирование рабочих мест: выбираешь дату и зону, видишь свободные места карточками и бронируешь. Все данные лежат в списках SharePoint, отдельного сервера нет.

Результат: сотрудник находит свободное место на нужную дату и бронирует его в SharePoint без отдельных таблиц.

Технические требования

  1. Фильтр по дате и зоне, занятые места скрыты
  2. «Мои бронирования» и отмена брони
  3. Уведомления об успехе, предупреждениях и ошибках
  4. К решению написаны HLD, руководство пользователя и инструкция по развёртыванию

Halden Intranet

личный / учебный проект
Разраб.Худоешко И.О.
СтекSPFx 1.23 · React · TypeScript · PnPjs

Интранет-портал на SharePoint Online: сайты отделов, новости, заявки, бронирование, отчёты. Одно SPFx-решение, версии 1.0 → 1.6.8.

Результат: новости, заявки, бронирование и отчёты компании собраны в одном интранет-портале.

Технические требования

  1. Новости с адресной аудиторией и формой для маркетинга
  2. Поиск Ctrl+K, тёмная тема, мобильное меню
  3. Скрипт развёртывания на PnP.PowerShell и автотесты
  4. Перед каждым релизом QA-аудит страниц: светлая и тёмная тема, 1280 и 390 px

Teams Photo Bot

учебный проект
Разраб.Худоешко И.О.
СтекC# · ASP.NET Core · Bot Framework v4 · Graph

Проект из экосистемы Microsoft 365: бот для Teams. По команде «photo» берёт фото профиля пользователя из Microsoft Graph и отвечает карточкой.

Результат: пользователь пишет боту «photo» в Teams и сразу получает карточку со своим фото профиля.

Технические требования

  1. Adaptive Card с именем и фото
  2. Доступ к Graph через приложение Entra ID (Azure.Identity)
  3. Запасной вариант, если фото нет
  4. Ключи не в репозитории: в настройках только заглушки
