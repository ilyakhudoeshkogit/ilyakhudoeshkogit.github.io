СтекC# · ASP.NET Core · Bot Framework v4 · Graph

Проект из экосистемы Microsoft 365: бот для Teams. По команде «photo» берёт фото профиля пользователя из Microsoft Graph и отвечает карточкой.

Результат: пользователь пишет боту «photo» в Teams и сразу получает карточку со своим фото профиля.

Технические требования

  1. Adaptive Card с именем и фото
  2. Доступ к Graph через приложение Entra ID (Azure.Identity)
  3. Запасной вариант, если фото нет
  4. Ключи не в репозитории: в настройках только заглушки

02 · Живое демо

Microsoft Teams · Photo Bot

Быстрые команды: 

Сначала попросите карточку командой photo.

Демо работает только в вашем браузере: профиль вымышленный, сообщения никуда не отправляются. Настоящий бот отвечает в Teams и берёт данные из Microsoft Graph.

Для демо нужен JavaScript.

03 · Схема обмена

Teams передаёт сообщение через Bot Service на эндпоинт бота. Бот получает токен приложения Entra ID через Azure.Identity, запрашивает фото пользователя в Microsoft Graph и отвечает Adaptive Card. Если фото нет (404), в карточке остаются инициалы. Ключи хранятся вне репозитория.
