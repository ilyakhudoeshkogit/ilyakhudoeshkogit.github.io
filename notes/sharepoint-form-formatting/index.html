Форматирование формы списка SharePoint: конструктор JSON

Соберите header, body и footer для «Форматировать форму»: иконка и заголовок, секции полей и кнопки в подвале — с живым предпросмотром и кнопкой «Копировать».

После форматирования столбцов логичный следующий шаг — сама форма элемента. В современных списках SharePoint у неё три зоны: шапка, тело с секциями и подвал. Писать JSON для каждой зоны руками долго: у header/footer одна схема (column formatting), у body — другая (sections). Поэтому собрал конструктор рядом с форматированием столбцов.

Чем body отличается от header

Header и footer — это дерево elmType, как у форматирования столбца: иконка Fluent, текст с токенами [$Title], ссылки. Body умеет только раскладку: массив sections с отображаемыми именами полей. Условный показ поля — отдельная формула в «Изменить столбцы», не часть body JSON. Пресеты взяты из моих проектов: согласования Executive Dashboard и брони Desk Reservation.

Схема сверена с Configure the list form на Microsoft Learn, 06.11.2026. Конструктор работает только в браузере и ничего никуда не отправляет.
