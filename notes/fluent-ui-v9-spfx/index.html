Fluent UI v9 в веб-части SPFx

Как в Executive Dashboard подключён Fluent UI v9: FluentProvider с темой, вкладки TabList, карточки и спиннер загрузки.

SPFx 1.23 из коробки тянет Fluent UI v8 (@fluentui/react). Для Executive Dashboard я взял v9, пакет @fluentui/react-components: стили в нём задаются токенами темы. Обе версии спокойно живут в одном package.json.

Провайдер темы

Компоненты v9 берут цвета и шрифты из FluentProvider. Его ставлю один раз, в корне веб-части. Без него кнопки и карточки останутся без стилей.

import {
  FluentProvider, webLightTheme, TabList, Tab,
  Card, Text, Spinner, SelectTabEventHandler
} from '@fluentui/react-components';

return (
  <FluentProvider theme={webLightTheme}>
    ...
  </FluentProvider>
);

Вкладки

Навигация по разделам сделана на TabList. В подписи вкладки сразу видно число записей, а выбранная вкладка хранится в состоянии React.

const handleTabSelect: SelectTabEventHandler = (event, data): void => {
  setSelectedTab(String(data.value));
};

<TabList selectedValue={selectedTab} onTabSelect={handleTabSelect}>
  <Tab value="overview">Overview</Tab>
  <Tab value="approvals">My Approvals ({approvals.length})</Tab>
  <Tab value="projects">Projects ({projects.length})</Tab>
  <Tab value="documents">Documents ({documents.length})</Tab>
</TabList>

Загрузка

Пока сервис читает списки, вместо вкладок показывается <Spinner label="Loading dashboard data..." />, а потом карточки Card с текстом Text. Как это выглядит, видно на скриншотах Executive Dashboard.
