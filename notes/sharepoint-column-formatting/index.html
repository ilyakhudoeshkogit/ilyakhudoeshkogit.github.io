Форматирование столбцов SharePoint без кода: конструктор JSON

Выберите, что подсветить: статус, число или срок, и получите готовый JSON для «Форматировать этот столбец» с живым предпросмотром и подсказками, где обычно ошибаются.

Не каждую задачу нужно решать веб-частью. Если заказчик хочет, чтобы просроченные задачи краснели, а согласованные заявки были зелёными, хватает форматирования столбца: это JSON, который вставляется прямо в настройки списка, без сборки и развёртывания. Писать его руками неудобно из-за вложенных if, поэтому собрал конструктор.

Пример:

Значение → уровень

Когда форматирования мало

Форматирование только рисует значение: оно не считает итоги, не ходит в другие списки и не умеет ничего сохранять, кроме простых действий вроде setValue. Как только нужны данные из двух списков или своя логика, это уже веб-часть, как Executive Dashboard. Классы sp-field-severity--* и значки Fluent берутся из документации Microsoft, поэтому выглядят одинаково в тёмной и светлой теме SharePoint.

Синтаксис сверен с документацией по форматированию столбцов на Microsoft Learn. Конструктор работает только в браузере и ничего никуда не отправляет.
