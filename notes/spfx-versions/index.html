Какой Node и React нужен моей версии SPFx

Интерактивная шпаргалка: версия SPFx → Node.js, TypeScript, React, gulp или Heft, поддержка SharePoint Server. Проверка node -v и package.json прямо в браузере.

Самая частая причина, почему проект SPFx не собирается после git clone, это не та версия Node или React. Я держу эту таблицу под рукой, поэтому сделал из неё инструмент: выберите версию или вставьте package.json, и он покажет, что ставить.

Что важно помнить

React ставится строго той версии, что в таблице, с флагом --save-exact: с более новой версией сборка проходит, а веб-часть молча ломается в браузере. С версии 1.22 вместо gulp используется Heft, поэтому старые команды gulp serve и gulp bundle в новых проектах не работают.

Локальный SharePoint Server поддерживает только старые версии: Subscription Edition до 1.5, 2019 до 1.4.1, 2016 с Feature Pack 2 до 1.1. Всё новее работает только в SharePoint Online.

Источник данных: таблица совместимости Microsoft Learn, сверено 30.10.2026. Инструмент работает только в браузере и ничего никуда не отправляет.
