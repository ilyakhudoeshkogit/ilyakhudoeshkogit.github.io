Шаблон сайта SharePoint без PowerShell-рутины: конструктор site script

Опишите списки, столбцы, меню, тему и хаб, и получите готовый site-script.json с постоянными GUID, скрипты регистрации для SPO и PnP PowerShell и схему будущего сайта.

Когда отделов на портале несколько, одинаковые списки и меню на каждом сайте руками не создают. Для Halden я писал PowerShell-развёртывание, но в SharePoint Online есть способ проще: шаблон сайта из JSON-скрипта действий. Его регистрируют один раз, и потом любой владелец сайта применяет его из меню «Применить шаблон сайта». JSON этот длинный, а Choice и подстановки в нём пишутся через экранированный CAML, поэтому собрал конструктор.

Site script или PnP-шаблон

Site script умеет только то, что есть в его списке действий: списки, столбцы, представления, меню, тему, хаб, установку решения и запуск Power Automate. Страницы с веб-частями, права на отдельные списки и данные он не создаёт. Для этого вызывают поток через triggerFlow или берут PnP-шаблон, как в Halden. Удобная середина: шаблон сайта создаёт каркас, а веб-части вроде Desk Reservation ставятся действием installSolution из каталога приложений.

Действия, параметры и лимиты сверены с Microsoft Learn 10.11.2026: обзор шаблонов сайтов (типы 64, 1, 68; 30 действий для Invoke-SPOSiteDesign, 300 действий или 100 000 символов при асинхронном применении) и JSON-схема. Конструктор работает только в браузере и ничего никуда не отправляет.
